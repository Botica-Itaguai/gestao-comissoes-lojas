# -gestao-comissoes
Aplicação web (página única, sem servidor) para calcular e acompanhar as comissões de vendas de múltiplas lojas — Botica, Lubotica e Loja Digital — e gerar uma planilha resumida para o setor de RH fechar a folha de pagamento.  Tudo roda direto no navegador: não há backend, banco de dados ou instalação. É só abrir o site.
